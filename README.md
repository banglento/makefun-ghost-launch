Launches the MakeFun Ghost coin (MFGHOST) on pump.fun with make.fun's press-kit ghost as its image, and hands in the coin's mint and the signature of the transaction that created it in LAUNCH.json. The program copies LAUNCH.json to the output directory for the bounty gate and validates its shape on the way.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
